# Captain's log, supplemental

Talk into a log instead of a text field, one library folder for everything Roger writes and meeting audio that doesn't get lost.

## New & Noteworthy

- **Log entries.** Sometimes you want to say something without typing it anywhere: a thought, a decision, what you just did. The new Log preset saves what you say as a Markdown file instead of inserting it at the cursor. Bind it to Caps Lock plus a modifier in Settings > Presets and record whenever you like. Each entry is its own file with frontmatter (time, length, language), so agents and knowledge bases can pick it up. While Roger records a log entry, the indicator turns green and says "Logging", then "Logged".
- **Any preset can write to the log.** Presets have a new Output setting: "Insert at cursor" or "Save as log entry". A log preset can also keep the recording as an .m4a file next to the entry.
- **One library folder.** Log entries, meetings and file transcripts now live together in `~/Documents/Roger/`, in `Logs`, `Meetings` and `Transcripts`, sorted by year and month. You can pick another folder in Settings > Recordings. On first launch Roger offers to move your existing meetings there. If you say no, they stay where they are and Roger still finds them.
- **Keep or drop meeting audio.** Settings > Recordings has a new "Keep audio after transcription" switch. Turn it off and Roger deletes mic.m4a and system.m4a once the transcript is written. It's on by default, and Roger never deletes the audio when a transcript came out empty or a track failed.

## Fixes

- **Meeting audio could be lost when encoding failed.** If Roger couldn't turn the recorded chunks into an audio file, it still deleted the chunks. They now stay on disk, and the meeting is offered for a retry.
- **A meeting couldn't be transcribed again.** If the speech model wasn't ready when a meeting ended, the audio was saved but Roger never offered it again. You now get the meeting back in the menu bar and can try again. If a retry rewrites a transcript, the old one is kept as transcript.previous.md.
- **New meetings refused to start after a failed one.** After an error at the end of a meeting, Roger could claim it was still recording.
- **Errors at the end of a meeting went unseen.** Problems while finishing a meeting (for example after the Mac went to sleep) now show up in the menu bar.

## Changes

- **File transcripts go to the library.** Dropped files are transcribed into `Transcripts` by default. "Next to the source file" is still an option.
- **Name clashes get a number.** A second transcript of `talk.mp4` is now `talk.mp4 1.md` instead of `talk.mp4-1.md`, like everything else in the library.

## Breaking changes

- **The meetings folder setting is gone.** If you picked your own folder for meetings, new meetings now go to the library folder. Set the library folder in Settings > Recordings if you want them somewhere else.
- **The custom folder for file transcripts is gone.** Roger still finds the transcripts that are already there.
- **Older transcripts next to their source are not tracked.** Roger only remembers transcripts it writes next to their source from now on.
