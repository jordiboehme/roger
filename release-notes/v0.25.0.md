# I know kung fu

Your agents can now learn what Roger heard: new log entries, meetings and transcripts go straight into their knowledge, without you copying a single file.

## New & Noteworthy

- **An MCP server for your library.** Agents should not have to search your Documents folder to find what's new. Roger.app now carries `roger-mcp`, a local MCP server (stdio only, nothing leaves your Mac). It has six tools: `status`, `get_changes`, `ack`, `get_item`, `list_items` and `search`. Roger itself does not have to run while an agent uses it. With Homebrew, `roger-mcp` is on your PATH.
- **Each agent sees only what's new.** Roger keeps a change log of everything it writes, edits, renames or moves to the Trash. Every agent (a "consumer") has its own bookmark. It asks for the changes since its last visit and confirms with `ack` once they are safe. If an agent fails halfway, it gets the same changes again next time. Nothing is skipped.
- **The ingest-roger skill.** It takes the new entries and writes them into your Crystalline knowledge base, grouped by meeting, day or transcript. Run `/ingest-roger <domain>` in Claude Code. Or use `scripts/ingest-roger.sh` from a LaunchAgent to do it every night (the README has an example).
- **Settings > Agents.** One place to set it all up. Roger finds Claude Code, Codex, Gemini CLI, Cursor, Copilot CLI and Kiro on your Mac. Install copies the skill and registers the server through each tool's own CLI. Roger never writes another app's config file. If a CLI is missing, you get the command or JSON to copy. Update keeps a backup of a skill you changed. Uninstall asks before it moves a changed skill to the Trash. The tab also lists every consumer with its bookmark, with Start over and Forget.
- **Claude Desktop.** "Add to Claude Desktop" builds an extension and opens it in Claude Desktop. "Save Skill for Claude Desktop" puts the skill as a zip in Downloads, ready to upload.
- **A hint when the skill is outdated.** After an update, the menu bar popover tells you when an installed skill is older than the one in Roger. Roger never updates a skill on its own.

## Fixes

- **Clicks on an entry in the library were ignored.** In 0.24.0 a row was only selected when you clicked its background, not its text or icon. Now the whole row works. Dragging an entry into Finder or a terminal still works.

## Changes

- **A new `.roger` folder in your library.** Roger keeps its change log and the agent bookmarks in `<library>/.roger/`. It's hidden and small. On the first start Roger fills it with your existing entries, so an agent can catch up on everything once.
- **Agents may need access to Documents.** When an agent starts `roger-mcp` from an app that macOS has not given access to your Documents folder, the tools tell you so. Allow it in System Settings > Privacy & Security > Files and Folders.

## Breaking changes

None.
