# Mayday

Roger now detects when macOS stops sending mic audio and offers a one-click relaunch.

## New & Noteworthy

- **Roger now recognizes a stuck macOS audio server.** macOS 26.5.x can quietly starve a long-running app of microphone data: permission granted, engine running, recording light on, zero audio. The mic test used to blame your privacy settings for this. It now names the real culprit and the Microphone tab offers a one-click Relaunch Roger button, with `sudo killall coreaudiod` as the escalation if it comes back. A dictation that hits this state shows the same guidance instead of silently typing nothing. The mic test also retries once before judging, so a sleepy microphone is not mistaken for a stuck one.
