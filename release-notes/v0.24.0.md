# Library computer access

Everything Roger writes now has a home you can open: one window to find, read, fix and hand off your logs, meetings and transcripts.

## New & Noteworthy

- **The library window.** Finder is fine for ten files, but not for a few hundred log entries. Open the library from the menu bar popover, with its own shortcut (Settings > General) or with a click on the last entry. The sidebar has All, Logs, Meetings and Transcripts, plus Unfinished for meetings that still need a transcript. The list is grouped by day.
- **Search, filter and sort.** Search looks at titles and full text and marks the hits in the preview. Filter by date and sort by date, title or length.
- **Read and edit in place.** The detail pane shows the Markdown with meeting screenshots as thumbnails. You can edit the text and rename an entry (the title changes, the file name stays). If the file changed on disk while you were editing, Roger asks before it overwrites anything.
- **Hand it to an agent.** Drag entries into a terminal or an agent chat, or copy their paths. That's the fastest way to feed a log into Claude Code and friends.
- **Move to Trash.** Entries go to the Trash, never straight to nowhere. A log takes its audio with it. A meeting takes its folder, but only when it's a real meeting folder and not one Roger is still writing.
- **A real app while it's open.** While the library window is open, Roger has a Dock icon and a menu bar, so Cmd-Tab and Cmd-, work. Close the window and Roger is a menu bar app again.

## Fixes

- **Retrying a meeting overwrote edited segment files.** If you had edited a segment of a meeting and then ran a retry, your edits were gone. Roger now keeps your version as `<name>.previous.md` next to the new one.
- **Leftover files after a meeting retry were hard to find.** A retry can leave files like `mic.leftover.m4a` or `transcript.previous.md`. They are now listed in the transcript's `sources` and in the library under Extra files, with a Clean Up button that moves them to the Trash once the meeting is done.
- **An error said "Try again" when there was nothing to try.** When a retry had already put the audio into a leftover file, the error now says that and names the file.

## Changes

- **Past recordings moved to the library.** Settings > Recordings no longer lists past recordings. You find them in the library window.

## Breaking changes

None.
