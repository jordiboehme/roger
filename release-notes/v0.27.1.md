# Please stand by

Small release, better feedback. Suggest Commands now shows what it is doing, and the preset settings put each option next to the step it belongs to.

## New & Noteworthy

- **Suggest Commands shows its steps.** Looking for coding agents can take a while, mostly when Claude Code checks all your MCP servers. You only saw a spinner, and it looked like Roger was stuck. Now the sheet lists each step and checks it off when it is done. A slow step shows how many seconds it has been running. If your shell or Claude Code does not answer, the step says so and Roger goes on with what it has.

## Fixes

- **A space at the end of a name did not show while you typed.** In the name of a preset or a command, the space only showed up after the next letter. The name field now has its label above it, and you see what you type.

## Changes

- **No more "Advanced" in Presets.** The formatting prompt, the custom dictionary and the rewrite prompt now sit under their switch in Processing, in the order the steps run. Each one shows while its step is on. To edit a prompt, turn its step on.

## Breaking changes

None.
