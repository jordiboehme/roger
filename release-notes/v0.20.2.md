# See you, Intel cowboy

Screenshot drops no longer crash Roger. Long recordings lose fewer words. Roger now needs Apple Silicon.

## Fixes

- **Dropping a screenshot onto the meeting overlay no longer crashes Roger.** The whole point of slide checkpoints is dragging the Shift-Cmd-4 thumbnail onto the recording overlay, and that exact gesture was the one drag Roger could not survive: a Swift concurrency assertion fired the moment the file promise arrived. One `@Sendable` later, the feature does what the README always claimed it did.

## New & Noteworthy

- **Long recordings lose fewer words.** FluidAudio 0.15.6 adds a repair pass for the seams between transcription chunks, where an hour-long meeting could quietly drop a phrase. It also keeps the final words of a recording from falling off the end.
- **Sturdier model downloads.** A first-launch download that stalls now recovers in seconds instead of hanging for half an hour, resumes where it left off and a flaky connection no longer throws away what was already fetched.
- **MP3 and M4A files transcribe more reliably.** Some compressed files used to fail at the very end of the file for no good reason.

## Breaking changes

- **Roger is now Apple Silicon only.** Transcription always ran on the Neural Engine, which Intel Macs don't have, so the universal build was a polite fiction. The download is smaller and nobody loses anything that ever worked.
