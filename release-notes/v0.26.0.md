# Fresh from the refit

Same ship, new inside: Settings got a new layout and its own window, Roger reads text from anywhere and a long list of small library and meeting bugs is gone.

## New & Noteworthy

- **Settings with a sidebar.** Ten tabs in a row were hard to scan. Settings now has a sidebar like System Settings. What you change most sits on top: General, Presets and Microphone. Then come Transcription (Speech Model, Text Model, Files) and Library (Library & Meetings, Agents), with Permissions and About at the bottom. Every pane uses the same layout, with a short note under each setting.
- **Settings in the Dock.** Settings now has its own window. While it is open, Roger shows up in the Dock and in Cmd-Tab, so you can switch back to it. Cmd-, opens it, and it remembers its size and the last pane.
- **Clearer names.** "Model" is now Speech Model: it turns your voice into text. "AI Provider" is now Text Model: it polishes and rewrites that text.
- **Built-in presets can be changed.** Edit Polished or Code the way you like it. Reset brings back the original. The preset list shows built-in and custom presets in two groups.
- **Text from anywhere.** Roger reads Markdown files with Windows line endings, a byte order mark or an older Windows encoding. They show up in the library with title, date and tags, and agents get them through the MCP server too. Files are only converted when Roger writes them anyway (for example when you edit an entry).
- **Apple Intelligence status.** The Text Model pane tells you if Apple Intelligence can really run, and why not if it can't.

## Fixes

- **Entries with Windows line endings showed as one long text.** Title, date and tags were missing. Now they are read like any other entry.
- **A missing library folder was created again.** With the library on a drive that was not connected, Roger could create an empty folder in its place. Now it says "Library folder not found" and creates nothing. A log entry you dictate meanwhile goes to the clipboard.
- **The library watched too much.** With the library folder gone, Roger watched the folder above it, sometimes all of Documents. Not any more.
- **Renaming in the library felt stuck.** The rename field stayed open on a click elsewhere, and the title updated late. Now a click elsewhere keeps the new name, Esc cancels and the title updates at once.
- **A saved entry could disappear from the list.** If it no longer matched the search, the detail showed "No Selection". Now it stays until you pick another entry.
- **Search, date and sort did nothing on Unfinished.** They are turned off there now.
- **Extra files did not update.** The list of extra files in a meeting now follows changes on disk, and a subfolder in a meeting folder shows up as one row.
- **Clean Up did nothing and said nothing** when a retry had started. Now it tells you.
- **The library list lost its place** when it filled up again after an empty search. It keeps the scroll position and focus now.
- **Logs sorted by title looked random.** They sort by the text you see now.
- **Hidden files and deep meeting folders.** Hidden Markdown files were picked up after a change, and meetings deeper in a folder were not updated. Both now follow the same rules as a full scan.
- **Unfinished meetings showed no audio** when only audio chunks were there. They show the chunks now.
- **Editing a linked entry replaced the link.** Roger now writes through the link to the real file.
- **Finalise was offered for folders that are not Roger meetings.** Not any more.
- **Relaunch Roger and unsaved edits got in each other's way.** Roger now asks about unsaved edits first, then relaunches.
- **A retry error did not name every leftover file.** It does now.
- **Saving an entry that is only frontmatter broke it.** The frontmatter stays closed now.
- **Settings showed German words in English text** on Macs set to German ("vor 8 Stunden"). Dates are English now.
- **MCP:** an agent that confirmed with `ack` after you switched the library could skip entries of the new library. `get_changes` now names the library and `ack` refuses another one. Errors name the tool and the library, and `status` no longer says "ready" when it cannot read the change list.
- **Codex configs with comments** showed the Roger server as not connected. They are read correctly now.

## Changes

- **Recordings can be 5 minutes long by default.** If you never changed the limit, it goes from 2 to 5 minutes. A limit you set yourself stays.
- **The change list is written to disk at once,** so a power cut cannot hand out the same entry twice.

## Breaking changes

None.
