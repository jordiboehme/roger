# None of those moments will be lost in time

Complete transcripts of long recordings, speaker turns that follow the conversation and transcripts your knowledge base can read.

## New & Noteworthy

- **Transcribe from Finder.** Dragging a file onto the menu bar icon isn't always handy. Right-click an audio or video file and pick Open With > Roger, or Services > Transcribe with Roger. If Roger is still loading its speech model, the file waits in line and starts when the model is ready.
- **Better speaker detection.** Roger used to decide who is speaking in 10 second windows, and the same person often got a new number at a window edge. It now looks at the whole recording at once. Speaker changes also land between words and at sentence ends, so a turn no longer starts with a "." or in the middle of a word. On a 78 minute meeting this cut the turns that start mid-sentence by more than half. Speaker detection takes a bit longer: about 2 minutes for a 78 minute recording.
- **Transcripts are Markdown with metadata.** Meeting transcripts and file transcripts now start with a frontmatter block: title, a one-line description, when the recording started and ended, its length, the number of speakers, the language and the models that did the work. Tools such as Obsidian or a knowledge base can index them as they are. For a dropped file the recording date comes from the file's metadata. If it has none, Roger uses the file's creation date and marks the date as inferred.
- **Screenshots show up everywhere.** Slide screenshots in a meeting transcript now have a caption with their time, and the link works in every Markdown viewer, not only in some.

## Fixes

- **Long recordings were cut off without a warning.** Some files, for example Teams recordings, contain stretches of audio that macOS can't decode. Roger stopped reading at the first one, so a 78 minute meeting came back as its first 20 minutes. Roger now skips a broken stretch and keeps going.
- **Files from cloud folders were ignored on drop.** A file in a synced folder that wasn't fully downloaded was silently rejected by the menu bar drop target.
- **No more warning on brew install.** The Homebrew cask no longer uses the deprecated `postflight` step.

## Breaking changes

- **Roger needs macOS 15 Sequoia or later.** The new speaker detection can crash on macOS 14 because of a bug in macOS itself. If you're still on macOS 14, stay on 0.21.0.
- **File transcripts are `.md` instead of `.txt`.** Transcribing `Meeting.mp4` now writes `Meeting.mp4.md`.
- **New frontmatter keys.** If you read meeting transcripts with your own scripts: the keys are snake_case now, and live segments use `status: draft` instead of `provisional`.
