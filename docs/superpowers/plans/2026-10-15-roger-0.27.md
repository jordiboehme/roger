# Roger 0.27.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Roger 0.27.0 "Make it so": logs with system audio, configured commands that run after Roger saves something, a data-access-only `ingest-roger` skill and a microphone priority list.

**Architecture:** Pure logic lives in small units with tests (`CommandTemplate` in RogerKit, `AgentCommand`, `InputChoice`, `CommandScheduler` with injected runner and launcher, `AudioMix`, the paragraphs variant of `LogEntryWriter`). The coordinator wires them in at existing seams: `startDictation`/`stopDictation`/`runPipeline`/`saveLogEntry`, `meetingRecorder.onTranscriptWritten` and the file transcript save. The UI adds one Settings pane (Commands) and edits the Presets, Library & Meetings, Files and Microphone panes.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, Core Audio process tap (existing `SystemAudioTap`), FluidAudio (existing pipeline), Swift Testing, xcodegen.

**Spec:** `docs/superpowers/specs/2026-10-15-roger-0.27-design.md`

## Global Constraints

- macOS 15.0+ deployment target, Swift 6 strict concurrency. `@MainActor` for every `@Observable` type SwiftUI observes.
- New files go under the existing source folders. After adding files run `cd Roger && xcodegen generate`, then restore `Roger/Resources/Roger.entitlements` (xcodegen empties it): `git checkout Roger/Resources/Roger.entitlements` when the diff shows it emptied.
- Build: `cd Roger && xcodebuild -project Roger.xcodeproj -scheme Roger -configuration Debug build` (never pass `CONFIGURATION_BUILD_DIR` on Debug).
- App tests: `cd Roger && xcodebuild test -project Roger.xcodeproj -scheme Roger -destination 'platform=macOS'`. RogerKit tests: `-scheme RogerKitTests`. Single test: add `-only-testing:RogerTests/<Suite>` or `-only-testing:RogerKitTests/<Suite>`.
- Tests must not construct `AppState` (it reads and writes the live UserDefaults). Use injected values and `FileManager.default.temporaryDirectory` subfolders.
- Logging via `os.Logger(subsystem: "com.jordiboehme.roger", category: ...)`.
- User-facing text (UI strings, skill, release notes): short plain sentences, no Oxford comma ("A, B and C"), never an em dash or en dash, use a hyphen.
- Settings panes use the kit in `UI/Settings/SettingsKit.swift` (`SettingsForm`, `SettingsRow`, `SettingsToggle`, `SettingsLabel`). No fixed font sizes, no custom cards. Settings open through `coordinator.openSettings(pane)`.
- New `Codable` fields decode with `decodeIfPresent ?? default` so stored JSON from 0.26 still loads.
- Commits: conventional commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`), no AI attribution, no `Co-Authored-By` trailer.

## Review Focus

1. A prompt or path with `'`, `"`, `$`, backticks, `;` or newlines must reach the command literally, never be run by the shell. (Task 2 tests these.)
2. A log with system audio where the other side never spoke must still save as a normal log with only "Me" paragraphs, and a denied Audio Capture permission must still save a mic-only log. (Task 8 tests the writer paths; Task 9 handles the tap failure.)
3. Several logs saved within seconds must not start parallel headless runs of the same command; one follow-up run must still happen. (Task 4 tests.)
4. Stored 0.26 settings (presets JSON, `selectedInputDeviceUID`) must load without losing the user's choices. (Tasks 1 and 10 test.)
5. A command whose working directory does not exist, or whose terminal is not installed, must fail visibly and never hang Roger. (Task 4 tests the directory; Task 5 handles the terminal.)

import Foundation

/// The library item a command runs for, as the placeholders see it.
public struct CommandItemInfo: Equatable, Sendable {
    public let file: String
    public let key: String
    public let title: String
    public let kind: String

    public init(file: String, key: String, title: String, kind: String) {
        self.file = file
        self.key = key
        self.title = title
        self.kind = kind
    }
}

/// Fills a command's prompt and command line. Placeholders are replaced in
/// one pass, so text inside a value is never expanded again.
public enum CommandTemplate {
    public static func shellQuote(_ value: String) -> String {
        "'" + value.replacingOccurrences(of: "'", with: "'\\''") + "'"
    }

    public static func renderPrompt(_ prompt: String, item: CommandItemInfo) -> String {
        substitute(prompt, values: itemValues(item))
    }

    public static func renderCommandLine(_ line: String, prompt: String, item: CommandItemInfo) -> String {
        var values = itemValues(item).mapValues(shellQuote)
        values["prompt"] = shellQuote(prompt)
        return substitute(line, values: values)
    }

    private static func itemValues(_ item: CommandItemInfo) -> [String: String] {
        ["file": item.file, "key": item.key, "title": item.title, "kind": item.kind]
    }

    /// Scans once from left to right. `{name}` with a known name is replaced,
    /// anything else is copied as it is.
    private static func substitute(_ text: String, values: [String: String]) -> String {
        var out = ""
        var rest = Substring(text)
        while let open = rest.firstIndex(of: "{") {
            out += rest[..<open]
            let afterOpen = rest.index(after: open)
            if let close = rest[afterOpen...].firstIndex(of: "}"),
               let value = values[String(rest[afterOpen..<close])] {
                out += value
                rest = rest[rest.index(after: close)...]
            } else {
                out += "{"
                rest = rest[afterOpen...]
            }
        }
        out += rest
        return out
    }
}
```

import Foundation

/// How a command runs.
enum CommandMode: String, Codable, CaseIterable, Identifiable {
    /// In the background, with a timeout. Nobody can answer questions.
    case headless
    /// In a new terminal window, so the user can answer.
    case interactive

    var id: String { rawValue }
    var displayName: String {
        switch self {
        case .headless: return "In the background"
        case .interactive: return "In a terminal window"
        }
    }
}

/// The terminal an interactive command opens in.
enum TerminalApp: String, Codable, CaseIterable, Identifiable {
    case terminal, iterm2, ghostty, warp

    var id: String { rawValue }
    var displayName: String {
        switch self {
        case .terminal: return "Terminal"
        case .iterm2: return "iTerm2"
        case .ghostty: return "Ghostty"
        case .warp: return "Warp"
        }
    }
    var bundleIdentifier: String {
        switch self {
        case .terminal: return "com.apple.Terminal"
        case .iterm2: return "com.googlecode.iterm2"
        case .ghostty: return "com.mitchellh.ghostty"
        case .warp: return "dev.warp.Warp-Stable"
        }
    }
}

/// A shell command the user configured in Settings > Commands. Log presets,
/// meetings and file transcripts can run one after Roger saved the item.
struct AgentCommand: Codable, Identifiable, Equatable, Sendable {
    var id: UUID
    var name: String
    /// Shell line; `{prompt}` and the item placeholders are shell-quoted.
    var commandLine: String
    /// Text with item placeholders, handed to `{prompt}`.
    var prompt: String
    /// "~" allowed. Expanded at run time.
    var workingDirectory: String
    var mode: CommandMode
    var terminal: TerminalApp
    /// Headless only.
    var timeoutMinutes: Int

    static let defaultTimeoutMinutes = 10
    static let headlessExampleLine = "claude -p {prompt}"
    static let interactiveExampleLine = "claude {prompt}"
    static let headlessExamplePrompt = "Use /ingest-roger to read what is new in Roger. Fold it into Crystalline with the ingestion method of crystalline-capture. Choose the domains by their routing. Keep tasks as [task] observations in the engrams they belong to. At the end, list the tasks you found."
    static let interactiveExamplePrompt = "Use /ingest-roger to read what is new in Roger. Fold it into Crystalline with the ingestion method of crystalline-capture. Choose the domains by their routing. Keep tasks as [task] observations in the engrams they belong to. At the end, list the tasks you found and ask me which ones to work on."

    init(
        id: UUID = UUID(),
        name: String,
        commandLine: String,
        prompt: String,
        workingDirectory: String,
        mode: CommandMode = .headless,
        terminal: TerminalApp = .terminal,
        timeoutMinutes: Int = AgentCommand.defaultTimeoutMinutes
    ) {
        self.id = id
        self.name = name
        self.commandLine = commandLine
        self.prompt = prompt
        self.workingDirectory = workingDirectory
        self.mode = mode
        self.terminal = terminal
        self.timeoutMinutes = timeoutMinutes
    }

    init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        id = try c.decode(UUID.self, forKey: .id)
        name = try c.decode(String.self, forKey: .name)
        commandLine = try c.decode(String.self, forKey: .commandLine)
        prompt = try c.decode(String.self, forKey: .prompt)
        workingDirectory = try c.decode(String.self, forKey: .workingDirectory)
        mode = try c.decodeIfPresent(CommandMode.self, forKey: .mode) ?? .headless
        terminal = try c.decodeIfPresent(TerminalApp.self, forKey: .terminal) ?? .terminal
        timeoutMinutes = try c.decodeIfPresent(Int.self, forKey: .timeoutMinutes) ?? Self.defaultTimeoutMinutes
    }

    static func newClaudeExample() -> AgentCommand {
        AgentCommand(name: "Ingest into Crystalline", commandLine: headlessExampleLine,
                     prompt: headlessExamplePrompt, workingDirectory: "~")
    }

    mutating func setMode(_ newMode: CommandMode) {
        let untouched = (commandLine == Self.headlessExampleLine && prompt == Self.headlessExamplePrompt)
            || (commandLine == Self.interactiveExampleLine && prompt == Self.interactiveExamplePrompt)
        mode = newMode
        guard untouched else { return }
        switch newMode {
        case .headless:
            commandLine = Self.headlessExampleLine
            prompt = Self.headlessExamplePrompt
        case .interactive:
            commandLine = Self.interactiveExampleLine
            prompt = Self.interactiveExamplePrompt
        }
    }

    func expandedWorkingDirectory(home: URL) -> URL {
        let trimmed = workingDirectory.trimmingCharacters(in: .whitespaces)
        if trimmed == "~" || trimmed.isEmpty { return home }
        if trimmed.hasPrefix("~/") { return home.appendingPathComponent(String(trimmed.dropFirst(2))) }
        return URL(fileURLWithPath: trimmed)
    }
}
```

@MainActor @Observable
final class CommandScheduler {
    init(runner: any CommandRunner, launcher: any TerminalLaunching,
         environment: @escaping @MainActor () async -> [String: String],
         home: URL = FileManager.default.homeDirectoryForCurrentUser)
    /// Last run per command id (headless and interactive launch failures).

    func markFailuresSeen()

    func waitUntilIdle() async

Behavior:
- `trigger` renders the prompt (`CommandTemplate.renderPrompt`) and the line (`renderCommandLine`).
- Working directory = `command.expandedWorkingDirectory(home:)`. If it is not an existing directory, record `.failed("The working directory <path> does not exist.")` and return without calling the runner or launcher.
- Interactive: call `launcher.launch(...)` in a Task. On throw record `.failed(error.localizedDescription)`. No queueing.
- Headless: if a run for `command.id` is active, store `pending[command.id] = (command, item)` (newest wins) and return. Otherwise start: record `.running`, call `runner.run(URL(fileURLWithPath: shell), ["-l", "-c", line], environment: await environment(), currentDirectory: dir, timeout: .seconds(command.timeoutMinutes * 60))`. `shell` is the user's login shell (`getpwuid(getuid())`, fallback `/bin/zsh`), same lookup as `CLILocator.loginShellPATH`. When it ends: record `.succeeded` for `.exited(0)`, otherwise `.failed("Exited with code N.")`, `.failed("Timed out after N minutes.")` or `.failed("Could not start: <reason>")`, and `outputTail = tail(of: stdout + "\n" + stderr)`. Then if `pending[id]` exists, remove it and start that run.
- A failure appends the id to `unseenFailures` (once). A success removes it.

        case succeeded
        case failed(String)

- [ ] **Step 4: Implement `CommandScheduler.swift`**

```swift
import Foundation
import Observation
import os

private let logger = Logger(subsystem: "com.jordiboehme.roger", category: "Commands")

protocol TerminalLaunching: Sendable {
    func launch(commandLine: String, workingDirectory: URL, terminal: TerminalApp) async throws
}

/// Runs configured commands after Roger saved an item. At most one headless
/// run per command: triggers during a run are merged into one follow-up run
/// with the newest item (an ingest takes everything pending anyway).
/// Interactive runs open a terminal each time and are not queued.
@MainActor @Observable
final class CommandScheduler {
    private(set) var lastRuns: [UUID: CommandRunRecord] = [:]
    private(set) var unseenFailures: [UUID] = []

    @ObservationIgnored private let runner: any CommandRunner
    @ObservationIgnored private let launcher: any TerminalLaunching
    @ObservationIgnored private let environment: @MainActor () async -> [String: String]
    @ObservationIgnored private let home: URL
    @ObservationIgnored private var active: [UUID: Task<Void, Never>] = [:]
    @ObservationIgnored private var pending: [UUID: (AgentCommand, CommandItemInfo)] = [:]
    @ObservationIgnored private var launches: [Task<Void, Never>] = []

    init(runner: any CommandRunner,
         launcher: any TerminalLaunching,
         environment: @escaping @MainActor () async -> [String: String],
         home: URL = FileManager.default.homeDirectoryForCurrentUser) {
        self.runner = runner
        self.launcher = launcher
        self.environment = environment
        self.home = home
    }

    func trigger(_ command: AgentCommand, item: CommandItemInfo) {
        let directory = command.expandedWorkingDirectory(home: home)
        var isDirectory: ObjCBool = false
        guard FileManager.default.fileExists(atPath: directory.path, isDirectory: &isDirectory), isDirectory.boolValue else {
            finish(command, startedAt: .now, outcome: .failed("The working directory \(directory.path) does not exist."), tail: [])
            return
        }
        let prompt = CommandTemplate.renderPrompt(command.prompt, item: item)
        let line = CommandTemplate.renderCommandLine(command.commandLine, prompt: prompt, item: item)

        switch command.mode {
        case .interactive:
            let started = Date.now
            launches.append(Task { [launcher] in
                do {
                    try await launcher.launch(commandLine: line, workingDirectory: directory, terminal: command.terminal)
                    self.finish(command, startedAt: started, outcome: .succeeded, tail: [])
                } catch {
                    self.finish(command, startedAt: started, outcome: .failed(error.localizedDescription), tail: [])
                }
            })
        case .headless:
            if active[command.id] != nil {
                pending[command.id] = (command, item)
                return
            }
            startHeadless(command, line: line, directory: directory)
        }
    }

    func markFailuresSeen() {
        unseenFailures.removeAll()
    }

    func waitUntilIdle() async {
        while true {
            let tasks = Array(active.values) + launches
            if tasks.isEmpty && pending.isEmpty { return }
            for task in tasks { await task.value }
            launches.removeAll()
            await Task.yield()
        }
    }

    private func startHeadless(_ command: AgentCommand, line: String, directory: URL) {
        let started = Date.now
        lastRuns[command.id] = CommandRunRecord(commandID: command.id, commandName: command.name, startedAt: started, outcome: .running)
        let shell = getpwuid(getuid()).flatMap { $0.pointee.pw_shell.map { String(cString: $0) } } ?? "/bin/zsh"
        let timeout = Duration.seconds(max(1, command.timeoutMinutes) * 60)
        active[command.id] = Task { [runner, environment] in
            let env = await environment()
            let result = await runner.run(URL(fileURLWithPath: shell), ["-l", "-c", line],
                                          environment: env, currentDirectory: directory, timeout: timeout)
            let outcome: CommandRunRecord.Outcome
            switch result.status {
            case .exited(0): outcome = .succeeded
            case .exited(let code): outcome = .failed("Exited with code \(code).")
            case .timedOut: outcome = .failed("Timed out after \(command.timeoutMinutes) minutes.")
            case .failedToStart(let reason): outcome = .failed("Could not start: \(reason)")
            }
            self.finish(command, startedAt: started, outcome: outcome,
                        tail: CommandRunRecord.tail(of: result.stdout + "\n" + result.stderr))
            self.active[command.id] = nil
            if let (next, item) = self.pending.removeValue(forKey: command.id) {
                self.trigger(next, item: item)
            }
        }
    }

    private func finish(_ command: AgentCommand, startedAt: Date, outcome: CommandRunRecord.Outcome, tail: [String]) {
        lastRuns[command.id] = CommandRunRecord(commandID: command.id, commandName: command.name,
                                                startedAt: startedAt, outcome: outcome, outputTail: tail)
        switch outcome {
        case .failed(let message):
            logger.warning("Command \(command.name, privacy: .public) failed: \(message, privacy: .public)")
            if !unseenFailures.contains(command.id) { unseenFailures.append(command.id) }
        case .succeeded:
            unseenFailures.removeAll { $0 == command.id }
        case .running:
            break
        }
    }
}
```

Note: `waitUntilIdle` loops because a finished run can start a follow-up. If the compiler complains about capturing `self` in the `Task` closures, the class is `@MainActor`, so `Task { ... }` inherits the main actor and `self` access is fine; use `[weak self]` only if needed for cycles (the scheduler lives as long as the coordinator, so a strong capture is acceptable).

import Foundation

/// Mixes the mic and system tracks of a log into one track for the kept
/// `.m4a`. Transcription never uses the mix.
enum AudioMix {
    static func mix(_ a: [Float], _ b: [Float]) -> [Float] {
        let count = max(a.count, b.count)
        var out = [Float](repeating: 0, count: count)
        for i in 0..<count {
            let sum = (i < a.count ? a[i] : 0) + (i < b.count ? b[i] : 0)
            out[i] = min(1, max(-1, sum))
        }
        return out
    }
}

```swift
import AVFoundation
import Foundation

final class SystemAudioRecorder: @unchecked Sendable {
    private let makeStream: () throws -> AsyncStream<[Float]>
    private let stopStream: () -> Void
    private let lock = NSLock()
    private var samples: [Float] = []
    private var consumer: Task<Void, Never>?

    init(makeStream: @escaping () throws -> AsyncStream<[Float]>, stopStream: @escaping () -> Void) {
        self.makeStream = makeStream
        self.stopStream = stopStream
    }

    static func live() -> SystemAudioRecorder {
        let tap = SystemAudioTap()
        return SystemAudioRecorder(
            makeStream: {
                let buffers = try tap.startStreaming()
                return AsyncStream { continuation in
                    let task = Task {
                        for await buffer in buffers {
                            continuation.yield(Self.floats(buffer.buffer))
                        }
                        continuation.finish()
                    }
                    continuation.onTermination = { _ in task.cancel() }
                }
            },
            stopStream: { tap.stop() }
        )
    }

    func start() throws {
        let stream = try makeStream()
        consumer = Task { [weak self] in
            for await chunk in stream {
                self?.append(chunk)
            }
        }
    }

    func stop() async -> [Float] {
        stopStream()
        await consumer?.value
        consumer = nil
        return lock.withLock { samples }
    }

    private func append(_ chunk: [Float]) {
        lock.withLock { samples.append(contentsOf: chunk) }
    }

    private static func floats(_ buffer: AVAudioPCMBuffer) -> [Float] {
        guard let data = buffer.floatChannelData else { return [] }
        return Array(UnsafeBufferPointer(start: data[0], count: Int(buffer.frameLength)))
    }
}
```

import Foundation

/// One entry of the microphone priority list (Settings > Microphone).
enum InputChoice: Codable, Hashable, Identifiable {
    /// Whatever macOS uses as the default input. Always in the list once.
    case systemDefault
    /// A device by Core Audio UID. `name` is the last known name, for display.
    case device(uid: String, name: String)

    var id: String {
        switch self {
        case .systemDefault: return "system-default"
        case .device(let uid, _): return uid
        }
    }

    static func migrated(selectedUID: String?, nameForUID: (String) -> String?) -> [InputChoice] {
        guard let uid = selectedUID else { return [.systemDefault] }
        return [.device(uid: uid, name: nameForUID(uid) ?? uid), .systemDefault]
    }

    static func repaired(_ list: [InputChoice]) -> [InputChoice] {
        var seen = Set<String>()
        var result = list.filter { seen.insert($0.id).inserted }
        if !result.contains(.systemDefault) { result.append(.systemDefault) }
        return result
    }

    static func resolve(_ list: [InputChoice], connectedUIDs: Set<String>) -> String? {
        for choice in list {
            switch choice {
            case .systemDefault: return nil
            case .device(let uid, _) where connectedUIDs.contains(uid): return uid
            case .device: continue
            }
        }
        return nil
    }
}
```

---
name: ingest-roger
description: Read and ingest Roger log entries, meeting transcripts and file transcripts. Use when the user asks to ingest, import, sync or read Roger, or runs /ingest-roger.
---

# Ingest Roger

Roger is a speech-to-text app on this Mac. Its MCP server `roger` serves log entries, meeting transcripts and file transcripts from Roger's library. This skill teaches you how to read them correctly: what is new, what changed and how to confirm what you processed, so nothing is read twice and nothing is missed.

This skill is about getting the data. What you do with it is up to you and the user's knowledge system. Process each item with your knowledge system's own ingestion method. With Crystalline, use the "Ingesting a source" section of the `crystalline-capture` skill.

Your client may show the tools with a prefix (for example `mcp__roger__get_changes`). Use whatever name it gives them.

## Arguments

`/ingest-roger [consumer]`. The consumer names who reads the changes. Roger remembers for each consumer what it confirmed. The default is `crystalline`. Use one consumer per knowledge system, so two systems never take each other's changes.

## Before you start

Call `status`. If the library is not ready, stop with `RESULT: failed: <the message from status>`.

## The loop

1. Call `get_changes(consumer: <consumer>, summary: true)`. Note `from`, `upTo`, `more`, `library` and the entries (key, event, kind, title, date).
2. Fetch each kind once. For every kind in the summary, call `get_changes(from: <from>, upTo: <upTo>, kinds: [<kind>])` with `from` and `upTo` from step 1. If that answer has `more: true`, call again with `from` set to its `upTo + 1` and the same `upTo` until `more` is false. Do not fetch the range again for each item.
3. Process every entry of the range (see "What an entry is").
4. Only when the whole range was processed, call `ack(consumer: <consumer>, upTo: <upTo from step 1>, library: <library from step 1>)`. Never ack the `upTo` of a call with `kinds`. If anything failed, do not ack: end with `RESULT: failed: <reason>`, so the next run repeats the range. If `ack` answers that the library changed, Roger now uses another library: start again at step 1 (this counts as a round).
5. If `more` in step 1 was true, start again at step 1. Do at most 5 rounds in one run.

## What an entry is

- Each entry is one item in its latest state. It starts with the line `==== roger entry <seq> ====`, lists its fields and has the item's Markdown after a blank line.
- Kinds: `log` (a short spoken note, sometimes with "Me" and "Other N" speakers when it also recorded the computer's sound), `meeting` (a transcript with speakers and optional screenshots) and `transcript` (a transcript of a media file).
- Events: `created`, `updated` and `deleted`. On `updated`, read the item again as a whole: the earlier version is gone. On `deleted`, what was made from the item may need to go. An entry with `missing: true` names an item whose file is gone; skip it and mention it in your summary.
- `roger://<key>` is the stable address of an item. Use it wherever your knowledge system records where something came from.
- `seq` grows with every change of an item, so it works as the version of what you read.
- Screenshots of meetings come as file paths. Open them when they show something that matters. If a path cannot be read, go on without it.

## Frontmatter

The frontmatter is Roger's metadata about the Markdown file. Keys such as `type`, `status`, `tags` and `sources` describe the file in Roger's library, not how you should store the knowledge. Do not copy them over as they are. Decide yourself what they tell you, for example when something was said (`started_at`), how long it took or which speakers there were.

## Other tools

- `get_item` reads one item by key.
- `list_items` lists items by kind and date.
- `search` finds items by text.

Use them when the user asks about something outside the change feed, for example a meeting from last month. They do not change what the consumer confirmed.

## Result

End with exactly one of these lines as the last line:

- `RESULT: ok` when nothing is left (`more` was false),
- `RESULT: ok more` when you stopped after 5 rounds and `more` was still true,
- `RESULT: failed: <reason>` when something went wrong. Do not ack the range in that case.
```

/// Pure decision: warm up when the resolved UID differs from the one last warmed up.
struct MicWarmUpTracker {

    mutating func didWarmUp(resolved: String?)
